# DemoMmnd — Public Preview

> **Live preview:** https://testdemoqwenai2025-creator.github.io/DemoMmnd/

## What this is

A standalone HTML site (no build step, no npm install, no backend) serving the Mmnd Observatory — a cross-era pairing of mathematical thought, rendered as living code.

## Files

```
DemoMmnd/
├── .nojekyll          # Disables Jekyll on GitHub Pages
├── README.md          # This file
├── index.html         # Home page (hero canvas + metrics + featured source + stages)
└── sources.html       # Sources page (KaTeX math + 3D cross-era network + demos)
```

## Deploy

1. Upload these files to the `DemoMmnd` repo's root (or `docs/` folder)
2. GitHub Settings → Pages → Source: main / root (or /docs)
3. Live at https://testdemoqwenai2025-creator.github.io/DemoMmnd/
