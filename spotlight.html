im2sim: from 3D MRI to blood flow in 0.5 seconds

An open-source Python library (PyTorch + PyTorch Geometric + VTK + PyVista) that builds hybrid image-graph neural networks to predict time-varying pressure and velocity fields directly from 3D medical images. Six interactive clips with rich animations. im2sim GitHub →

Better approach: four improvements

im2sim is excellent engineering. The 0.5s inference is clinically transformative. But four architectural additions would move it from "fast" to "trustworthy." Each connects to our Physics+ML curriculum.

1. FNO-style spectral layer for the field head

Replace the pixel-wise 3D CNN output with a Fourier Neural Operator spectral layer. Mesh-independent, captures global flow structure, and supports zero-shot super-resolution.

2. Physics-informed loss (divergence-free constraint)

Add ∇·u = 0 as a soft penalty at collocation points — exactly the PINN pattern. Training-only cost; structural mass conservation at inference.

3. Ensemble or Bayesian uncertainty

The surgeon sees u(x,t) ± σ(x,t), not just a point estimate. Train an ensemble of 5-10 models; the variance across the ensemble is the uncertainty estimate.

4. Active learning loop

Flagged low-confidence cases are queued for traditional CFD verification. The CFD results are added back to the training set — the discrepancy modeling pattern applied to the training pipeline.

The 0.5s number gets im2sim through the clinic door. Physics-informed loss, uncertainty, and active learning are what keep it in the clinic.
