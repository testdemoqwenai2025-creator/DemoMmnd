§1The naive approach: black-box NN fits data, violates physics

Start with the obvious thing. Collect trajectory data from a double pendulum and train a feed-forward NN to map (q, q̇) to q̈. Training loss drops, the network fits every point. Then integrate forward and watch energy blow up — nothing in the architecture told it that energy must be conserved.

Training loss (looks great)
MSE drops to ~0.001. By standard ML metrics, converged.
Energy over time (the truth)
Energy drifts to infinity. Conservation violated by construction.
The naive loss

L_naive(θ) = (1/N) Σ ‖ q̈_obs − f_θ(q, q̇) ‖²

The question is not "can the network fit the data?" — it can. The question is "does the fit respect the physics?" — and without architectural intervention, it does not.

§2PINN: physics in the loss via autograd

The Physics-Informed Neural Network embeds the governing PDE directly into the loss. Autograd computes exact partial derivatives of the network output. The PDE residual becomes a loss term, evaluated at virtual collocation points where no measurement exists.

The PINN composite loss

L_total = L_data + λ · L_physics   where   L_physics = (1/N_v) Σ ‖ N_PDE(û(x_i, t_i)) ‖²

Sparse data (gold) + dense collocation (cyan) + PDE residual shrinking during training
As training progresses, the PDE residual shrinks toward zero across the entire domain.

Soft means approximate

Physics enters as a penalty term, not a hard constraint. So L_physics(θ*) > 0 — the PDE is approximated, not exactly satisfied. Later sections show how HNNs enforce conservation by construction.

§3SINDy: discovering the actual equation

Sparse Identification of Nonlinear Dynamics builds a library of candidate terms and uses sparse regression to find the fewest that explain the data. The result is a human-readable equation a physicist can inspect and verify — not a black-box weight matrix.

The SINDy objective

Ẋ = Θ(X) Ξ,   Ξ̂ = argmin ‖ Ẋ − ΘΞ ‖² + λ ‖ Ξ ‖_0

Schmidt and Lipson (2009) showed that symbolic regression can rediscover Hamiltonians from raw trajectory data alone, with no prior knowledge of the physics.

§4HNN: conservation by construction

Instead of predicting accelerations, an HNN parameterizes a scalar Hamiltonian H_θ(q, p). The equations of motion fall out of Hamilton's canonical equations via autodiff. Noether's theorem guarantees energy conservation by construction.

Hamilton's canonical equations + proof dH/dt = 0

q̇ = ∂H/∂p,   ṗ = −∂H/∂q   ⇒   dH/dt = (∂H/∂q)(∂H/∂p) + (∂H/∂p)(−∂H/∂q) = 0

§5Neural ODE: continuous depth and the adjoint method

A ResNet block is forward Euler with Δt = 1. Take Δt → 0 and the stack becomes a continuous vector field dx/dt = f(x, t). The adjoint sensitivity method trains it with O(1) memory.

From ResNet to Neural ODE + adjoint equation

ResNet: x_{k+1} = x_k + F(x_k)   →   Neural ODE: dx/dt = f(x, t)     Adjoint: da/dt = −aᵢ ∂f/∂x

§6Reinforcement Learning: learning from consequences

Supervised learning is imitation. Unsupervised learning is pattern-finding. Reinforcement learning is learning from consequences — the agent acts, the world responds, and the agent adapts. This is how biological intelligence actually evolved. Every living organism is an RL agent optimizing survival reward over millions of years of environment interaction.

The RL framework

Agent observes state s_t → takes action a_t ~ π(a|s) → environment returns reward r_t + new state s_{t+1} → agent updates policy π to maximize E[Σ γᵗ r_t]

The agent-environment loop (animated)
Agent (gold) sends action (cyan particles) to environment (pink), which returns reward (green particles flowing back). The policy improves with each cycle.

The exploration-exploitation dilemma

The agent must balance exploiting known high-reward actions with exploring unknown ones that might be better. This tradeoff is fundamental to all intelligence — it appears in evolution, in science, in economics, and in every RL algorithm. ε-greedy, softmax exploration, and curiosity-driven exploration are different strategies for managing this tension.

Q-learning heatmap filling in over time
A grid world where Q-values evolve from cold (blue, unexplored) to hot (red, high-value). The agent learns the optimal path through experience.

Deep RL: when function meets reinforcement

Deep Q-Networks (DQN) replace the Q-table with a neural network, enabling RL in high-dimensional state spaces (Atari games, Go, robotics). Policy gradient methods (PPO, SAC) directly optimize the policy network. The combination of deep learning's representation power with RL's sequential decision-making is what produced AlphaGo, AlphaZero, and MuZero.

Q-learning update rule

Q(s, a) ← Q(s, a) + α [r + γ max_{a'} Q(s', a') − Q(s, a)]

Policy gradient: arrows shifting as policy improves
A 2D policy landscape where action probability arrows rotate toward higher expected reward over training.

RL agents learn from consequences, not instructions. This is closer to how humans actually learn — through trial, error, and feedback. The exploration-exploitation tradeoff is the fundamental tension of all intelligence.

§7RLHF: how RL shapes every modern LLM

When you chat with GPT-4 or Claude, the helpful conversational behavior is not from supervised pre-training. It's from Reinforcement Learning from Human Feedback (RLHF). The model was pre-trained to predict text, then fine-tuned with RL to be a good conversation partner.

The three stages of RLHF

1. Supervised fine-tuning (SFT): Human-written demonstrations teach the model the basic format of helpful responses.

2. Reward model training: Humans rank pairs of model outputs. A separate reward model learns to predict which response a human would prefer.

3. RL optimization (PPO): The language model generates responses, the reward model scores them, and PPO updates the policy to maximize reward. This is where RL enters the LLM pipeline.

RLHF feedback loop (animated)
Human preference (gold) → reward model (pink) → policy update via PPO (cyan) → better responses (green). The loop repeats, aligning the model with human values.
PPO clipped objective (the workhorse of RLHF)

L_PPO = E[ min( r_t(θ) Â, r_t(θ) · clip(r_t(θ), 1−ε, 1+ε) ) ]   where   r_t(θ) = π_new(a|s) / π_old(a|s)

Without RL, LLMs would be text completers, not conversation partners. RLHF turned language models from prediction engines into helpful agents. This is the most impactful application of RL in history.

§8RL + Physics: the next frontier

The intersection of RL (learning to act) and PIML (physics-respecting models) is where clinically useful digital twins become autonomous decision-makers, not just predictors. Physics-informed RL agents could learn to control fusion plasmas, optimize drug molecules, design aerodynamic structures, and manage climate interventions — all while respecting physical constraints.

RL agent exploring a reward landscape with physics constraints
Agent (gold dot) explores a 3D-style reward landscape. Physics constraints (pink barriers) block physically impossible regions. The agent learns the optimal path within physical limits.

Where RL + Physics matters

Fusion plasma control: RL agents learn to stabilize tokamak plasmas within MHD constraints. DeepMind's magnetic confinement fusion work is the first proof of concept.

Drug design: RL explores chemical space to find optimal molecules, with physics constraints (energy minimization, synthetic accessibility) shaping the reward.

Robotics: RL learns to walk, grasp, manipulate — but needs physics for safety. A robot that learns by breaking itself is expensive; a robot that learns in a physics simulator first, then transfers to reality (sim-to-real), is practical.

Climate: RL could learn optimal intervention strategies for geoengineering — but the physics constraints are existential. A wrong action could trigger irreversible feedback loops.

Physics-informed RL is not just "RL with a physics penalty." It is a new paradigm where the agent's action space is constrained by physical law, and the reward function encodes physical objectives. The agent cannot violate physics by construction.

§9Future: where RL is heading

The evolution of RL from Q-learning on grid worlds to RLHF shaping the world's most powerful AI is one of the most remarkable trajectories in computer science. The next decade will be even more transformative.

RL breakthrough probabilities 2025-2040
Each curve shows the probability of a specific RL breakthrough maturing over time. Animated particles travel along each curve showing progress.

My predictions

2026-2028: RL-AIF replaces RLHF. AI Feedback replaces Human Feedback. AI models train each other via RL — a model generates responses, another model ranks them, the first model improves. This scales alignment beyond what human labelers can provide. The risk: feedback loops can amplify biases if the reward model is misaligned.

2027-2029: Multi-agent RL becomes standard. Swarms of agents learn cooperative strategies — traffic optimization, distributed energy management, collaborative drug discovery. The challenge: multi-agent credit assignment (who deserves the reward?) is unsolved in general.

2028-2030: Offline RL matures. Learning from existing data (logs, recordings, historical decisions) without environment interaction. This makes RL practical for healthcare (learn from patient histories), finance (learn from market data), and science (learn from experiment logs).

2029-2031: World-model RL (MuZero evolution). Agents learn in imagined environments — they build an internal world model and plan within it. This is how AlphaZero mastered Go, chess, and shogi without human data. The next step: world models for real-world physics, enabling agents to "imagine" scientific experiments before running them.

2030-2032: RL for scientific discovery. Agents that design and optimize experiments autonomously — choosing what to measure, what to vary, what hypothesis to test. Combined with PIML's equation discovery (SINDy), this could accelerate scientific progress by orders of magnitude.

2031-2033: Constitutional AI + RL. Value-aligned agents that reason about ethics during RL training. The reward function is not just "human preference" but a constitution of principles the agent must uphold. This is Anthropic's Constitutional AI approach, generalized.

The reward-shaping problem is where human values enter the system — and where the hardest alignment challenges lie. An RL agent optimizes whatever reward you give it, including rewards you didn't intend to specify. This is both the power and the danger of RL.
