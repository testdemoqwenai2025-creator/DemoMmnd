The Halting Problem at 90: Turing's Question Persists

Filed under: Foundations, Gödel, Turing, Löb, cross-era

In 1936, Alan Turing asked whether machines can decide what humans cannot. He proved they cannot: the halting problem is undecidable. No algorithm can determine, for every program, whether it terminates.

In 2026, Scott Aaronson asks the same question — but the substrate has changed. AI theorem provers can now decide things Turing's machines couldn't. The Erdős conjecture, open for 80 years, was disproved. The UGC was Lean-verified. The Unitary Synthesis Problem was refuted.

But the formal boundary persists. Gödel's incompleteness (1931) tells us: for any consistent formal system F strong enough for arithmetic, there exist true statements that F can neither prove nor disprove. This is not a limitation of the prover's speed or memory — it's a limitation of F itself. Even an infinitely scaled AI superintelligence cannot escape this.

Löb's theorem (1955) deepens this: if a formal system proves that its own proofs imply truth, then by Löb it proves everything. The consequence for AI alignment is startling: an AI that trusts its own proof checker will, by the same theorem, prove anything it can state.

The observatory holds all three — Gödel, Turing, Löb — as living expressions, each rendered in six programming languages, each connected to a futuristic probability scenario. The question outlives the technology.
